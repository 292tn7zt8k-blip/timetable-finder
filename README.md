# 시간표 공유 v4 — PIN 인증

GitHub Pages + Supabase + OpenAI Edge Function 기반 시간표 공유 사이트입니다.

## 현재 인증 방식
- 최초: 학번 + 이름을 비공개 명단과 대조
- 처음 등록하는 학번: 본인이 6자리 숫자 PIN 설정
- 이후: 학번 + PIN으로 로그인
- PIN 원문은 DB에 저장하지 않고 bcrypt 해시만 저장
- 로그인 세션 토큰도 DB에는 SHA-256 해시만 저장

## 보호 규칙
- 김서하(2502) 제외, 학생 원장 158명
- AI 분석은 학생당 최대 2회
- 1회차 분석 후 10분 뒤에 2회차 가능
- 유료 AI 호출 직전에 횟수를 차감하므로 반복 호출로 2회를 초과해 과금할 수 없음
- 시간표를 저장한 학생만 다른 학생 시간표 / 공강 / 같은 수업 조회 가능
- 과목은 자유 입력이 아니라 표준 과목 ID 드롭다운으로 저장
- AI가 목록 밖 단어를 만들지 못하게 JSON Schema enum을 사용하고 불확실한 칸은 UNKNOWN 처리
- 분석 감사 로그에 학번, 요청 시각, 성공/실패, IP 해시를 기록
