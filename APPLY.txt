적용 순서

1) Supabase SQL Editor
   - supabase-classrooms-typing.sql 전체를 한 번 Run

2) Supabase Edge Functions > analyze-timetable
   - 현재 index.ts 내용을 analyze-timetable-index.ts 전체 내용으로 교체 후 Deploy
   - 기존 OPENAI_API_KEY 등 환경변수는 그대로 사용

3) GitHub
   - index.html
   - style.css
   - app.js
   - core.js
   위 4개를 기존 파일에 덮어쓰기

주의
- 기존 학생 schedule 데이터는 삭제/초기화하지 않습니다.
- 기존 학생은 다시 시간표를 등록하지 않아도 됩니다.
- 기존 학생의 교실은 빈값으로 시작하며, 새 AI 분석/수정 시부터 저장됩니다.
- 교실 허용값: 201~208, 운동장, 정보교과실
- 한 수업에 운동장/208처럼 복수 장소 저장 가능
- 같이 듣는 친구 매칭에는 교실을 사용하지 않습니다.
- 채팅 입력 중 표시는 최근 5초 내 입력 신호가 있을 때만 나타납니다.
