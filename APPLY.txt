적용 순서

1. Supabase SQL Editor
   - supabase-chat-photo-upgrade.sql 전체 Run

2. Supabase Edge Functions
   - 새 함수 chat-media 생성
   - edge-functions/chat-media/index.ts 전체 붙여넣기
   - Deploy

3. 기존 analyze-timetable Edge Function
   - analyze-timetable-index.ts 내용으로 index.ts 전체 교체
   - Deploy

4. GitHub
   - index.html
   - style.css
   - app.js
   - core.js
   4개 덮어쓰기

변경 사항
- DM JPG/PNG/WEBP 사진 전송, 최대 5MB
- 사진+텍스트 동시 전송
- 사진 누르면 확대
- 사진은 private Storage + 채팅 참가자 세션 검증 후에만 접근
- 모바일 채팅방 상단 헤더 항상 화면 위 고정
- 하단 입력창 항상 화면 아래 고정
- 메시지 말풍선 폭 확대 및 한글 과도한 줄바꿈 수정
- 교실은 과목 아래 작고 연한 회색으로 표시
- 신규/재분석 시간표 원본 이미지를 private timetable-images 버킷에 보관

주의
- 과거에 원본 시간표 이미지가 저장되지 않았던 학생의 교실은 자동 복원할 수 없음
- 기존 시간표/채팅/PIN 데이터는 삭제하지 않음
